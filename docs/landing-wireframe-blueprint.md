# Wireframe landing — BASE per la landing page Rosa Segnale (agg. 2026-07-20)

File: `rosa-segnale-landing-wireframe.svg` (+ .png). Bassa fedeltà, una pagina.
Questo wireframe è la **base approvata** su cui costruire la landing vera.

## Struttura (dall'alto)
1. **HEADER** — logo + menu (Home · Come funziona · Contatti) + bottone **PROVA LA DEMO**
2. **HERO** — titolo + sottotitolo + bottone primario **PROVA LA DEMO** + "Scopri" + nota "gratis · nessun dato richiesto" + immagine
3. **COME FUNZIONA** — 3 card (i 3 passi: bottone → ascolto → ponte)
4. **CTA · DEMO** — fascia dedicata con bottone **PROVA LA DEMO** (elemento PIÙ importante: porta al prototipo)
5. **FOOTER** — logo + link rapidi + risorse + contatti + "112 · 1522"
